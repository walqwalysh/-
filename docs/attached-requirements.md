# المتطلبات المستخلصة من الملف المرفق

يتضمن الملف المرفق تصوراً موسعاً لمنظومة محاسبية ومصرفية. تُنفّذ المزايا التي تتوافق مع تطبيق **المحاسب الذكي** بوصفها أدوات محاسبية محلية، مع الحفاظ على أن الحسابات والقيود والأرصدة تبدأ من صفر وأن كل حركة ناتجة تلتزم بالقيود المزدوجة.

| المجال | المتطلبات المعتمدة للتنفيذ |
|---|---|
| التشغيل | وضع ليلي، نسخ احتياطي واستعادة محليان، طباعة، تصدير Excel، وحالة مزامنة محلية. |
| القيود | مراجع مستندات مرقمة، عملة مرجعية وسعر صرف اختياري، عكس القيد بقيود متوازنة، ورمز تحقق قابل للمشاركة. |
| المستندات | سند قبض أو صرف، وسيلة الدفع، الطرف، الحساب المقابل، معاينة ونسخة قابلة للطباعة. |
| التقارير | ميزان مراجعة، تفصيل قائمة الدخل والمركز المالي، تنبيه حالة التوازن، وتقارير الذمم. |
| الرقابة | سجل تدقيق محلي، مراكز تكلفة اختيارية، ومتابعة النقدية المنقولة والمقاصة. |
| الإدخال الذكي | مسح فواتير لتحضير مسودة قيد وإدخال صوتي لتحضير مسودة قيد؛ لا تُرحّل أي حركة تلقائياً قبل مراجعة المستخدم. |
| غير المعتمد افتراضياً | أسعار صرف ثابتة، أرصدة افتتاحية، قيود عينة، وبيانات شركات أو فروع أو عملاء تجريبية. |

يُعامل كل اقتراح صادر من التعرف الضوئي أو الصوت أو الذكاء الاصطناعي كمجرد **مسودة**. لا يجوز له إنشاء قيد فعلي إلا بعد اختيار الحسابات ومراجعة المستخدم واجتياز تحقق التوازن.
